Dual class: "a class feat of your class" now offers both classes. A dual class is one class item, so PF2e only knew its first class, and a feat like Natural Ambition listed only that class's feats (a Thaumaturge - Cleric could not pick the cleric's Healing Hands). On a dual class sheet, Tongs now widens such a ChoiceSet to either class, as the Dual Class variant allows. Sheets with one class are unchanged, and if PF2e ever changes underneath, the picker simply falls back to PF2e's own list.
