Dual class for players. "Dual class…" (the C×2 button in the Tongs tray) lets a player pick one of their own
character sheets and two classes from the community macro's class compendiums (plus SF2e's). The designated
GM's browser checks the request (their sheet, real classes, not the same one twice), builds the dual class
item with the macro's rules, and tells the GM "Tongs gave Lai's Kibwe the Fighter - Wizard dual class."; the
item then lands on the player's sheet from their own browser, replacing the old class, so PF2e asks the
player (not the GM) for the class features' choices. Fixes three of the macro's bugs on the way: medium
armour, the martial rule clean-up, and rules both classes share.
